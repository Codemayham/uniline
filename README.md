# Uniline Promotions prototype

Responsive React + Vite catalogue and enquiry website prototype.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Before production

- The catalogue entries and product photos are illustrative sample content; replace them with verified inventory and approved images.
- Add the verified WhatsApp business number (international digits only) to `WHATSAPP_NUMBER` in `src/App.jsx`.
- Verify the telephone and location details shown in the page before publication.
- The quote form is intentionally demo-only and does not transmit or store submissions. Connect a secure backend with server-side validation and spam protection before enabling real enquiries.
- Configure the production domain and canonical URL before launch.
